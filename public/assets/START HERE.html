OraDesk: setup guide for the clinic

OraDesk runs on this laptop. It needs no internet and no monthly payment. Follow steps 1 to 3 once. Then use the OraDesk icon on the desktop every day.

1Install Google Drive (free, for backups)

Do this first, so the installer finds Google Drive and keeps a second copy of every backup there.

  1. Open google.com/drive/download and install Google Drive for desktop.
  2. Sign in with the clinic's Google account.
  3. Turn on 2-step verification for that Google account.

No Google Drive? You can skip this step. Then copy backups to a pen drive every week (step 5).

2Install OraDesk

Windows: double-click Install OraDesk (Windows).bat.

Mac: right-click Install OraDesk (Mac).command and choose Open.

  1. If Python is missing, the Windows installer installs it. This is free and takes a few minutes. On a Mac, install Python from python.org/downloads first.
  2. For a new clinic, press Enter when the installer asks about moving from another laptop.
  3. Press Enter to accept the Google Drive backup folder.
  4. OraDesk opens in the browser. An OraDesk icon appears on the desktop.

3Create the password

  1. Type a password with at least 12 characters, two times.
  2. Keep Keep me signed in on this computer ticked. The laptop then stays signed in.
  3. Write the password on paper and keep it in a locked drawer.

4Daily use

  • OraDesk starts by itself when the laptop starts.
  • Double-click the OraDesk icon on the desktop to open it.
  • Press Lock at the top right only if other people use this laptop.

5Backups

  • OraDesk saves a backup on the laptop every 30 minutes while you work. It keeps the last 14 days.
  • It also copies each backup to the Google Drive folder OraDesk Backups. Google Drive keeps the last 60 days there.
  • Once a week, open the Today screen. If a yellow bar shows, click Download backup and save the file to a pen drive.

Backup files hold patient records. Keep the pen drive locked away. Do not send backup files on WhatsApp or by email.

6New laptop, or the laptop stops working

  1. On the new laptop, do step 1 (Google Drive) and sign in with the same Google account.
  2. Run the installer (step 2).
  3. When it asks about moving from another laptop, open the Google Drive folder OraDesk Backups. Drag the newest file (oradesk-YYYY-MM-DD.sqlite3) into the installer window and press Enter.
  4. Sign in with the old password. All records are back.

7Forgot the password

Windows: press Windows + R, type cmd and press Enter. Then type these two lines, pressing Enter after each:

cd %LOCALAPPDATA%\OraDesk
py -3 server.py --reset-password

Mac: open Terminal and type cd ~/OraDesk && python3 server.py --reset-password

Records stay. Every computer must sign in again with the new password.

8Keep the laptop safe

  • Set a Windows or Mac login password on the laptop.
  • Turn on disk encryption: BitLocker or Device encryption on Windows, FileVault on a Mac.
  • Do not lend the laptop to people outside the clinic.
